# PermutiveAPI 6.8.2

PermutiveAPI 6.8.2 is a backward-compatible dependency-policy patch for the optional dataframe integration.

## Fixed

- The `dataframe` extra now requires `pandas>=2,<3`.
- The development extra uses the same pandas constraint so CI and contributor environments remain on the supported pandas 2.x line.
- Pandas remains optional and is not added to the core installation.

## Compatibility

This release does not change the public SDK, transport, resource, query, plugin, MCP, or governance surfaces. Existing pandas 2.x consumers remain supported. Pandas 3 is intentionally excluded until its compatibility is explicitly validated.

The 6.8.2 candidate must pass the protected Python, AI-native, security, release-metadata, contract, replay, performance, build, clean-wheel, and public-PyPI verification gates. Publication uses PyPI Trusted Publishing and the exact immutable candidate artifacts produced by the release workflow.
