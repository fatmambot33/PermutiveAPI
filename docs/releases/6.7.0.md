# PermutiveAPI 6.7.0

PermutiveAPI 6.7.0 completes the platform-proof and operational-reliability roadmap.

## Highlights

- Deterministic AI evaluation scorecard and governed end-to-end scenarios.
- Versioned capability negotiation across tools, AgentKit, Codex, and MCP.
- Secret-safe actionable failures and seven executable installed-package recipes.
- Measured installation-to-first-success under a five-second budget.
- Generated endpoint coverage and additive-versus-breaking schema drift detection.
- Sanitized HTTP recording and deterministic canonical-client replay.
- Shared synchronous and asynchronous rate-limit coordination.
- Atomic credential rotation with immutable in-flight generations.
- Stress, cancellation, performance, and artifact-tampering tests.
- Manual credential-gated read-only live integration testing.
- Immutable release-candidate manifests verified before PyPI and GitHub Release.

## Upgrade

```bash
python -m pip install --upgrade PermutiveAPI==6.7.0
```

## Compatibility

The release is backward compatible with the documented 6.x canonical and compatibility surfaces. Existing `PermutiveClient`, `AsyncPermutiveClient`, resource, query, plugin, MCP, and governed workflow entry points remain available.

## Security

Credentials, request payloads, query values, authorization headers, cookies, and raw exception messages are excluded from committed evidence. Live tests require an explicitly protected environment and an approved read-only path.

## Validation

The release candidate must pass Python 3.9–3.13, strict Pyright, NumPy-style docstrings, generated contract checks, replay validation, performance budgets, deterministic evaluations, clean wheel installation, optional extras, SBOM generation, artifact attestation, and release-manifest verification.
