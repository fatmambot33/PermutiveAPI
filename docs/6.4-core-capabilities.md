# PermutiveAPI 6.4 core capabilities

This release slice adds four canonical, backward-compatible capabilities.

## Async SDK

Install `PermutiveAPI[async]` and use `AsyncPermutiveClient`, or inject an `AsyncTransport` in tests and custom environments. Async requests, pagination, resource operations, retries, context management, and cleanup follow the synchronous SDK semantics.

## Configuration and security

`PermutiveConfig` is the shared typed configuration model. Explicit values override environment values. `Secret` redacts credentials from string and representation output. Remote endpoints require HTTPS; local HTTP requires an explicit development opt-in.

## Query composition

The existing Pydantic query AST remains the validation authority. `QueryExpression` and the builder functions provide a compact immutable layer for composing event, property, segment, AND, and OR expressions before validation or submission.

## Compatibility

Existing synchronous constructors and raw query payloads remain supported. The async dependency is optional and is not imported by core synchronous modules.
