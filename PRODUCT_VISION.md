# Product Vision

## Purpose

PermutiveAPI is the Python SDK for the Permutive platform.

## Mission

Build the best Python SDK for Permutive: simple, reliable, typed, and production-ready.

## Principles

- Developer experience first.
- Explicit over magic.
- Simple over clever.
- Reliability over features.
- Public APIs are long-term commitments.
- Documentation, tests, and types are part of every feature.

## Scope

PermutiveAPI includes API clients, authentication, typed models, utilities, error handling, documentation, examples, and tests.

It does not include applications, business workflows, dashboards, customer-specific code, or unrelated utilities.

## Decision Order

1. Developer experience
2. Simplicity
3. Reliability
4. Consistency
5. Maintainability
6. Performance

## Guiding Question

> Does this make PermutiveAPI a better Python SDK?

If the answer is not clearly yes, reconsider the change.
